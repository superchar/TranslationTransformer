Building encoder-decoder transformer based on [Attention Is All You Need](https://arxiv.org/abs/1706.03762) paper, for educatinal purposes. [BPE](https://en.wikipedia.org/wiki/Byte-pair_encoding) algorithm is used for tokenization. [OPUS](https://opus.nlpl.eu/) english to russian translation dataset is used to train the model.
